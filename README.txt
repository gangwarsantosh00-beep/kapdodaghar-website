KAPDO DA GHAR WEBSITE
=======================

Files:
- index.html
- style.css
- script.js
- assets/kapdo-da-ghar-logo.jpg
- assets/kd-icon-logo.jpg

GoDaddy upload:
1. Open your GoDaddy hosting/cPanel File Manager.
2. Open public_html (or the folder connected to kapdodaghar.in).
3. Upload index.html, style.css, script.js and the assets folder.
4. Keep the assets folder in the same location as index.html.
5. Visit https://kapdodaghar.in

The WhatsApp, call, email, Instagram and Google Maps buttons are already configured.
